# Navis v0.1.1

This patch release adds Kubernetes maintenance setup scripts for CloudNativePG.

- Bootstrap a dedicated maintenance login for a fresh install or check ownership privileges for an existing login.
- Grant backup reads for the AGE catalog and existing graph schemas before `pg_dump` runs.
- Create or reuse the Kubernetes Secret, backup PVC, and maintenance pod, then run the read-only migration plan.

The database target remains migration **021**. If your v0.1.0 deployment is already upgraded, you can use the host scripts without rerunning database migrations. Build the v0.1.1 container from the release tag to deploy the updated application version.

[Database roles and Kubernetes scripts](https://github.com/Zen1988/navis/blob/v0.1.1/docs/DATABASE_ROLES.md) · [Podman upgrade guide](https://github.com/Zen1988/navis/blob/v0.1.1/docs/PODMAN.md)
