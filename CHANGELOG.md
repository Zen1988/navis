# Changelog

## [0.1.0] - 2026-11-17

First tagged development release. See the [release notes](docs/releases/v0.1.0.md).

- Namespace topology orchestration, named applications and server/IP membership.
- Content-based graph version reuse, history/comparison and build/recheck dates.
- Managed inventory evidence labels and unmanaged network visibility gaps.
- Ingestion collection progress, expected/input/processed counts and failure diagnostics.
- Caller-owned trace sessions, lifecycle metadata and explicit audit history.
- 90-day eligible-history archival and one-year audit retention tools.
- Backup/checksum-ledger database upgrades through migration 021.
- Rootless Podman build/upgrade guide and versioned container metadata.

This release remains a prototype with incomplete vendor/network semantics; it
does not establish arbitrary end-to-end reachability or production readiness.
